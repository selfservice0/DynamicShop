# DynamicShop interactive demo

Public sample of the six website designs: Classic, Market Hall, Inventory, Nova, Chest GUI, and DSX Exchange. Includes eight coordinated palettes and twelve accent presets. Preview DSX at https://selfservice0.github.io/DynamicShop/?design=dsx#catalog. All prices, transactions, and admin controls are demonstration data. Nothing connects to or changes a Minecraft server. Appearance and watchlists stay in the visitor's browser; other demo edits reset on reload.

Built from `design-preview/` with `node design-preview/build-admin.cjs` followed by `node design-preview/publish-site.cjs`.
