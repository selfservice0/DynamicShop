# DynamicShop interactive demo

Public sample of the five website designs. All prices, transactions, and admin controls are demonstration data. Nothing connects to or changes a Minecraft server. Appearance and watchlists stay in the visitor's browser; other demo edits reset on reload.

Built from `design-preview/` with `node design-preview/build-admin.cjs` followed by `node design-preview/publish-site.cjs`.
